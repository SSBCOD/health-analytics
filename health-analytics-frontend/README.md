# 🏥 Health Analytics Frontend

Красивый минималистичный интерфейс для системы аналитической оценки здоровья.

## ✨ Дизайн

- **Шрифты**: 
  - Playfair Display - элегантный serif для заголовков
  - DM Sans - чистый modern sans для текста
  - JetBrains Mono - monospace для чисел
- **Цветовая палитра**: Тёплые нейтральные тона + зелёные акценты
- **Стиль**: Минимализм с мягкими тенями и glass эффектом

## 🚀 Запуск

```bash
npm install
npm run dev
```
